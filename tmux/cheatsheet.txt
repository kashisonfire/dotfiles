
  TMUX KEYS              prefix = C-a
  ──────────────────────────────────────
  C-a C-a  sends a literal C-a to zsh
           (beginning-of-line still works)

  PANES
    C-a |        split side-by-side
    C-a -        split stacked
    M-← ↑ ↓ →    move between panes
    C-a z        zoom pane in / out
    C-a x        close pane
    C-a M-← ↑ ↓ →  resize by 5
    C-a { }      swap pane back / forward
    C-a M-1..5   preset layouts

  WINDOWS
    C-a c        new window (same dir)
    C-a g        new window, dir from zoxide
    M-1 .. 6     jump without the prefix
    C-a 1 .. 9   jump to window N
    C-a n  p     next / previous
    C-a ,        rename window
    C-a &        close window
    C-a w        pick from a list

  SESSIONS
    ts           the session picker
    C-a d        detach  (ts to return)
    C-a $        rename session
    C-a s        pick from a list
    C-a C-s      save every session
    C-a C-r      restore them

  COPY  /  MOUSE
    C-a [        enter copy mode
      v          start selection
      y          yank to Windows clipboard
      q          leave copy mode
    drag         select + copy with mouse
    click        focus pane / switch window

  CONFIG
    C-a r        reload ~/.tmux.conf
    C-a space    menu (which-key)
      ?          this cheatsheet
    C-a ?        every binding tmux knows
    C-a /        describe one key

  ──────────────────────────────────────
  q to close
